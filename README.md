# Food Storage Management System

CCT College Dublin
Module: Algorithms and Constructs
Assessment: CA-1

This project implements a food storage management system in Java
using a Stack data structure with a maximum capacity of 8 items.

The system will manage:
- Food name
- Weight
- Best-before date
- Storage time

The application will support:
- Add
- Remove
- Peek
- Display
- Search
- Exit
